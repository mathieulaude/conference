# Goodbye GitHub : un site statique hébergé avec Codeberg et Bunny

GitHub est souvent un réflexe pour héberger du code et automatiser le déploiement d'un site statique sur GitHub Pages, mais existe-t-il une alternative tout aussi simple ?
Je vous propose un retour d’expérience sur l'utilisation de Codeberg et Bunny Storage.
L’objectif : construire une chaîne de déploiement simple, légère et entièrement européenne, sans serveur à administrer.
Après une présentation des ces deux acteurs européens, nous verrons comment organiser le dépôt, automatiser la génération et publier le site sur Bunny Storage.
Un retour concret sur une alternative européenne à GitHub, de la gestion du code jusqu’à la mise en ligne.
